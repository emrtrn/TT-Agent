# Ünite materyalleri

Bu klasör, 8. sınıf üretim kaynaklarını ve üretilen PDF'leri içerir. 7. sınıf materyalleri güncellendikleri diğer projeye taşınmıştır.

```text
units/
└── 8_sinif/
    └── unit1/ ... unit8/        # 8. sınıf materyalleri
```

Her `unitN` klasörü, önce Markdown kaynaklarını (`U[N]_MD_...`) barındırır. PDF çıktıları aynı ünite klasörüne yalnızca Markdown onayı sonrasında eklenir. Öğrenci sınavı ile cevap anahtarı ayrı dosyalardır.

Yeni bir üniteye başlamadan önce:

1. Ünite klasöründeki hazırlık planının **Oturum devri** bölümü okunur.
2. `referans/8_sinif/00_resmi_kaynak.md` ve canlı MEB ünite sayfası doğrulanır.
3. `workflow/00_yol_haritasi.md` ile `workflow/04_etkilesimli_sunum_entegrasyonu.md` incelenir.
4. Her oturum sonunda dosya durumları, sıradaki tek iş, açık kararlar ve doğrulama kanıtları hazırlık planında güncellenir.
